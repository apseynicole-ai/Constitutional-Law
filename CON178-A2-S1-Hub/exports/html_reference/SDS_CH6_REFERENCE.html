Big Picture: Continuous vs Discrete

The fundamental shift from Chapter 5 to Chapter 6

Core Concept Discrete vs Continuous
▼
📊 Discrete (Chapter 5)
  • Counts whole numbers: 0, 1, 2, 3…
  • Examples: number of successes, events in an interval
  • Uses PMF (Probability Mass Function)
  • P(X = x) is meaningful and non-zero
  • P(X < 5) ≠ P(X ≤ 5) in general
Deeper explanation — why exact points disappear in continuous distributions

For a discrete variable, the possible outcomes are separated: 0, 1, 2, 3. A single outcome can hold probability mass, so P(X=2) can be meaningful.

For a continuous variable, the possible outcomes form an unbroken line. There are infinitely many possible decimal values between any two numbers, so one exact point has no width. Since probability is area and a single point has zero width, its area is zero.

QuestionDiscrete logicContinuous logic
P(X=5)Can be non-zeroAlways 0
P(X<5) vs P(X≤5)Different because 5 may matterSame because P(X=5)=0
Main pictureProbability at bars/pointsProbability over intervals/areas
MCQ trap: If the variable is continuous and an option says an exact point has positive probability, that option is usually testing Chapter 5 vs Chapter 6 confusion.
📈 Continuous (Chapter 6)
  • Takes any value in an interval: 18.3, 4.72…
  • Examples: height, waiting time, download speed
  • Uses PDF (Probability Density Function)
  • P(X = x) = 0 always — exact points have zero probability
  • P(X < 5) = P(X ≤ 5) — they are the same!
Key Rule Probability = Area for Continuous Variables
▼

For continuous distributions, probability is always the area under the curve over an interval, never the height of the curve at a single point.

P(a < X < b) = area under f(x) from a to b
⚠ The Biggest Continuous Rule

f(x) is the height (density), not the probability.

The height can even be greater than 1! (e.g. Uniform(0, 0.5) has height = 2)

Probability only comes from area.

In Chapter 6, < and ≤ are effectively the same.
Because P(X = any exact point) = 0, including or excluding an endpoint doesn't change the probability.
P(X < 5) = P(X ≤ 5) for any continuous variable.

Deeper explanation — area, height and density

A density value f(x) is like the height of the curve at a point. It helps create area, but it is not probability by itself.

Think of a rectangle: if the height is 0.25 and the width is 2, the probability is 2 × 0.25 = 0.5. The height alone is not enough.

DistributionHow area is found
UniformRectangle area: base × height
NormalArea under bell curve from z-table/calculator
ExponentialArea under decreasing curve using 1−e^(−λx) or e^(−λx)
Sanity check: Area/probability must be between 0 and 1. Density/height can sometimes be bigger than 1.

Formula Sheet Decoder

Every formula you need — with symbols explained, when to use it, and the biggest trap

Normal X ~ N(μ, σ²)
▼
X ~ N(μ, σ²) E[X] = μ ← mean is the centre of the bell Var(X) = σ² ← spread of the bell z = (x − μ) / σ ← standardise to z-score (use SD, not variance!) x = zσ + μ ← inverse: recover x from z (for percentile questions)
SymbolMeaningWatch out
μPopulation mean / centreGiven directly in N(μ, σ²)
σ²Variance (spread squared)Second value in N(μ, σ²) is variance, not SD
σStandard deviationσ = √(σ²) — always take square root!
zStandardised scoreDivide by σ, not σ²
⚠ Biggest Normal Trap

X ~ N(100, 256) → σ² = 256, so σ = √256 = 16, not 256.

Always take the square root before computing z-scores.

Deeper explanation — how to read normal notation

X ~ N(μ, σ²) tells you two things: the centre of the bell curve and the spread of the bell curve.

PartMeaningExample
μMean / centreIn N(100, 16²), μ=100
σ²VarianceIn N(100, 16²), σ²=256
σStandard deviationσ=16

The z-score turns any normal variable into a standard normal variable. After standardising, you can use the normal calculator/table.

Non-negotiable: z-scores use standard deviation, not variance. If you see N(100,256), use σ=16.
Uniform X ~ Uniform(a, b)
▼
X ~ Uniform(a, b) f(x) = 1/(b−a), a ≤ x ≤ b ← height of the rectangle E[X] = (a+b)/2 ← midpoint of the interval Var(X) = (b−a)²/12 ← on formula sheet P(X < t) = (t−a)/(b−a) ← shortcut (not on formula sheet) P(c < X < d) = (d−c) × 1/(b−a) ← rectangle area method
⚠ Biggest Uniform Trap

Time does NOT automatically mean exponential. If the question says "between 3.5 and 5.5 minutes" with no λ rate, it is uniform.

Also: f(x) is height, not probability. A height of 0.5 is fine.

Deeper explanation — why uniform probability is rectangle area

Uniform means the distribution is flat. No part of the interval is more likely than another part of the same width.

The full interval from a to b must have total probability 1. That is why the height is:

height = 1 / (b−a)

QuestionWhat you use
Probability between two valuesWidth of wanted interval × height
MeanMiddle of the interval: (a+b)/2
SpreadInterval width b−a controls variance
Trap: Do not treat the lower bound as 0 unless it actually is 0. For P(X<t), use (t−a)/(b−a), not t/(b−a).
Exponential X ~ Exp(λ)
▼
X ~ Exponential(λ) f(x) = λe^(−λx); x ≥ 0 ← density function E[X] = 1/λ ← mean waiting time Var(X) = 1/λ² ← variance (NOT 1/λ) P(X < x) = 1 − e^(−λx) ← "within / less than" P(X > x) = e^(−λx) ← "more than" (complement shortcut) p = −(1/λ) · ln(1−α) ← inverse: find time from probability α
⚠ Biggest Exponential Traps
  • Units must match: λ is per minute → x must be in minutes
  • Mean ≠ λ: If E[X] = 10, then λ = 1/10 = 0.1
  • Greater than: use e^(−λx), not 1 − e^(−λx)
  • Variance = 1/λ², not 1/λ
Deeper explanation — lambda as a rate, not a time

In an exponential distribution, λ measures how quickly events happen. A larger λ means events happen more often, so the waiting time is shorter.

GivenMeaningMean waiting time
λ=2/week2 events per week1/2 = 0.5 weeks
λ=0.2/min0.2 events per minute1/0.2 = 5 minutes

The two most-used formulas are complements of each other:

P(X<x)=1−e^(−λx) and P(X>x)=e^(−λx).

Units rule: The expression λx must be unitless. That only happens when λ and x are in matching time units.
Normal Approx. Binomial → Normal
▼
X ~ Binomial(n, π) → Xₐ ~ Normal(μ, σ²) Checks: nπ > 5 AND n(1−π) > 5 μ = nπ σ² = nπ(1−π) σ = √[nπ(1−π)] ← take square root! Then apply continuity correction (±0.5) before z-scores
Original WordingCorrected Boundary
P(X = x)P(x−0.5 < Xₐ < x+0.5)
P(X ≤ x) — at mostP(Xₐ < x+0.5)
P(X < x) — fewer thanP(Xₐ < x−0.5)
P(X ≥ x) — at leastP(Xₐ > x−0.5)
P(X > x) — more thanP(Xₐ > x+0.5)
Deeper explanation — why the 0.5 continuity correction exists

A binomial variable can only land on whole numbers, like 59, 60, 61. A normal variable can land anywhere, like 59.3 or 60.8.

So each binomial bar gets represented by a small normal interval. The whole number 60 lives from 59.5 to 60.5.

Discrete binomial wordingContinuous normal area
Exactly 6059.5 < Xₐ < 60.5
At least 60Start at 59.5 because 60 is included
More than 60Start at 60.5 because 60 is excluded
Best routine: Translate the discrete wording first, then apply the 0.5 correction. Do not correct before deciding whether the value is included.

Distribution Recognition Table

Master this first — identify the distribution before touching a formula

Distribution Key Trigger Words What It Measures Formula Used
Normal bell-shaped, symmetric, mean + SD/variance given Continuous measurements (height, IQ, weight) z = (x−μ)/σ
Uniform equally likely between bounds, between a and b, no rate given Equally spread values over an interval (d−c)/(b−a)
Exponential waiting time, time between/until, rate λ given Waiting time between events 1 − e^(−λx)

Deeper explanation — how to choose the distribution before calculating

Chapter 6 MCQs often test recognition more than arithmetic. Before touching a formula, decide what X actually measures.

If X measures...Likely distributionWhy
A measurement with mean and SDNormalThe variable is continuous and bell-shaped
A value equally likely between limitsUniformFlat rectangle over an interval
A waiting time until next eventExponentialTime between arrivals/events
A count in a fixed intervalPoissonDiscrete count, not a waiting time
Successes out of trialsBinomial / normal approximationDiscrete successes, sometimes approximated
Danger pair: “12 per hour” can lead to Poisson or exponential. Count in the hour = Poisson. Time until next = exponential.
⏱ 10-Second MCQ Decision Routine
  1. 1
    Is X a count (whole number) or a measurement/time?
  2. 2
    Are there n trials with success/failure? → Binomial. Says "approximate"? → Normal Approx.
  3. 3
    Is it number of events in a fixed interval? → Poisson
  4. 4
    Is it waiting time / time between events + rate λ? → Exponential
  5. 5
    Is it equally likely between two bounds? → Uniform
  6. 6
    Bell-shaped / mean + SD given? → Normal
  7. 7
    Does it give a percentage and ask for a value? → Inverse method
Deeper explanation — using the routine under MCQ pressure

The routine works because it prevents you from jumping to a formula too early. One keyword alone can mislead you.

For example, “time” does not always mean exponential. If the question says “time is uniformly distributed between 1 and 5,” the bounds and “uniformly” are more important than the word time.

  1. Underline what X measures.
  2. Circle the distribution clue: rate, bounds, mean/SD, successes, approximate.
  3. Write the method name before writing a formula.
  4. Only then calculate.
Exam habit: In MCQs, spend 5 seconds deciding the distribution. That often saves you from 2 minutes of wrong calculation.

Normal Distribution Question Cards

4 types of normal questions — teach, recognise, example, traps

Card 5.1 P(X < x) — Less Than
▼

Recognition Clues

"Find the probability that X is less than / below / within…" + normal distribution clues (mean, SD).

Method

  1. 1
    Identify μ and σ (take √ of variance if needed)
  2. 2
    Compute z = (x − μ) / σ
  3. 3
    Use calculator left-tail: P(Z < z)
📌 Worked Example

X ~ N(65, 8²). Find P(X < 72).

z = (72 − 65) / 8 = 7/8 = 0.875 P(Z < 0.875) ≈ 0.8092

Answer: 0.8092 — Since 72 > 65 (mean), expect probability > 0.5. ✓

⚠ MCQ Traps
  • N(100, 256) → σ = 16, not 256. Take the square root!
  • z can be negative if x < μ — that is fine.
Deeper explanation — why less-than normal questions use the left tail

Most normal calculators/tables naturally give the area to the left of a z-score: P(Z<z). That is exactly what a “less than” question asks for.

If x is above the mean, z is positive and the left-tail probability should be bigger than 0.5. If x is below the mean, z is negative and the probability should be below 0.5.

Position of xSign of zExpected left-tail probability
Below μNegativeLess than 0.5
Equal to μ00.5
Above μPositiveMore than 0.5
Quick check: If x>μ and your P(X<x) answer is below 0.5, you probably used the wrong tail or wrong SD.
Card 5.2 P(X > x) — Greater Than
▼

Method

Calculator gives left-tail. For greater-than, use the complement.

z = (x − μ) / σ P(X > x) = 1 − P(Z < z)
📌 Worked Example

X ~ N(65, 8²). Find P(X > 80).

z = (80 − 65) / 8 = 1.875 P(Z < 1.875) ≈ 0.9696 P(X > 80) = 1 − 0.9696 = 0.0304

Answer: 0.0304 — 80 is far above the mean, so a small right-tail probability makes sense. ✓

⚠ MCQ Trap

The most common mistake is choosing 0.9696 — the left-tail answer. The question says "greater than", so you must subtract from 1.

Deeper explanation — why greater-than normal questions need the complement

The normal calculator/table usually gives what is to the left of the boundary. A greater-than question asks what is to the right.

The whole curve has area 1. So right-tail probability is:

P(X>x) = 1 − P(X<x)

This is not just a formula trick. It is because left area + right area = total area under the curve = 1.

MCQ trap: When the boundary is far above the mean, the left-tail may be a large number like 0.9696. The actual right-tail answer is the small complement, 0.0304.
Card 5.3 P(a < X < b) — Between Values
▼
P(a < X < b) = P(Z < z_b) − P(Z < z_a) = upper left-tail − lower left-tail
📌 Worked Example

X ~ N(65, 8²). Find P(60 < X < 70).

z₁ = (60−65)/8 = −0.625 → P(Z < −0.625) ≈ 0.2660 z₂ = (70−65)/8 = 0.625 → P(Z < 0.625) ≈ 0.7340 P(60 < X < 70) = 0.7340 − 0.2660 = 0.4680

Answer: 0.4680

⚠ MCQ Trap

Always subtract: upper cumulative − lower cumulative. Doing it backwards gives a negative answer — which is impossible for probability.

Deeper explanation — why between-values questions use subtraction

A “between” probability is the area trapped between two cutoffs. Normal calculators usually give cumulative area from the far left, not the middle strip directly.

So you calculate two left-tail areas:

  • Area left of the upper boundary
  • Area left of the lower boundary

Then subtract the lower cumulative area from the upper cumulative area.

Picture it: upper left-tail area contains the middle strip plus everything below the lower boundary. Subtracting the lower left-tail leaves only the middle strip.
Impossible answer check: A negative probability means you subtracted in the wrong order.
Card 5.4 Inverse Normal — Find x from %
▼

Recognition: "Find the value such that …% are below/above it" — given probability, find x.

Step 1: Convert wording to left-tail probability "Only 10% higher" → left-tail = 0.90 "Top 5%" → left-tail = 0.95 "Bottom 5%" → left-tail = 0.05 Step 2: Find z from calculator (inverse normal) Step 3: x = zσ + μ
📌 Worked Example

IQ ~ N(100, 16²). What IQ is such that only 10% have a higher IQ?

"Only 10% higher" → left-tail = 0.90 z ≈ 1.2816 x = (1.2816)(16) + 100 = 120.5

Answer: 120.5

⚠ MCQ Traps
  • "Only 10% higher" does NOT mean use 0.10. Convert to left-tail: 0.90.
  • Remember x = zσ + μ, not x = z + μ.
  • For "below" wording, z may be negative — that is fine.
Deeper explanation — how to translate inverse normal wording

Inverse normal questions give the probability and ask for the data value. The hardest part is converting the words into a left-tail area.

WordingLeft-tail probability to use
Bottom 20%0.20
20% below0.20
Top 10%0.90
Only 10% higher0.90
90% below0.90

After finding z, convert back to the original scale using x=zσ+μ.

Trap: “10% higher” is right-tail language. Most inverse normal calculators need left-tail input, so convert it to 1−0.10=0.90.
Mini Examples Source Examples: X ~ N(18, 5²)
▼

These three examples all use X ~ N(18, 5²), so μ = 18, σ = 5. Practise converting to z then using the calculator.

📌 P(X < 18.6)
z = (18.6 − 18) / 5 = 0.6/5 = 0.12 P(Z < 0.12) ≈ 0.5478

Answer: 0.5478
18.6 > 18 (mean) so answer > 0.5 ✓

📌 P(X > 18.6)
z = 0.12 (same as above) P(X > 18.6) = 1 − 0.5478 = 0.4522

Answer: 0.4522
Complement of P(X < 18.6) ✓

📌 P(17.4 < X < 18) — Between Values
z₁ = (17.4 − 18)/5 = −0.12 → P(Z < −0.12) ≈ 0.4522 z₂ = (18 − 18)/5 = 0.00 → P(Z < 0.00) = 0.5000 P(17.4 < X < 18) = 0.5000 − 0.4522 = 0.0478

Answer: 0.0478 — Narrow interval just below the mean → small probability ✓

📌 Inverse Normal — P(X < x) = 0.20, find x
Left-tail = 0.20 → z ≈ −0.8416 (negative because below mean) x = zσ + μ = (−0.8416)(5) + 18 = −4.208 + 18 = 13.792 ≈ 13.8

Answer: x ≈ 13.8 — 20% of values are below 13.8 ✓

Deeper explanation — how the N(18, 5²) examples link together

All four mini examples use the same normal curve. The only thing that changes is the boundary or direction.

QuestionCore move
P(X<18.6)z is slightly positive, so answer slightly above 0.5
P(X>18.6)Complement of the previous answer

Study trick: When practising normal questions, label each one as left-tail, right-tail, between, or inverse before calculating.

Uniform Distribution Question Cards

Rectangle area + bounds — once the idea clicks, it's the easiest distribution

🔑 The Big Idea: Uniform = Rectangle

Every value between a and b is equally likely. The graph is a flat rectangle with:

Height = 1/(b−a) ← constant across the whole interval Total area = base × height = (b−a) × 1/(b−a) = 1 ✓

Think of it like a flat table: every point on the surface is equally accessible.

Deeper explanation — why the rectangle has total area 1

A probability distribution must have total probability 1. In the uniform distribution, the graph is a rectangle from a to b.

The base is b−a. To make the total area equal to 1, the height must be 1/(b−a).

PartMeaning
Full baseb−a
Height1/(b−a)
Total area(b−a)×1/(b−a)=1
Trap: A probability is an area. The height alone is not the probability of a single value.

Clue in QuestionThink

Card 6.2 — Height of the Rectangle

f(x) = 1/(b−a)
📌 Example: X ~ Uniform(0,10)

f(x) = 1/(10−0) = 0.1

0.1 is the height — not the probability of any value. P(X = 5) = 0.

Card 6.3 — P(c < X < d)

P(c < X < d) = (d−c) × 1/(b−a)
📌 Example: X ~ Uniform(0,10). Find P(5 < X < 7).
height = 1/10 = 0.1 base = 7−5 = 2 P = 2 × 0.1 = 0.2

Answer: 0.2

⚠ Trap

The base is d−c (the width of the interval you want), NOT d or c on their own.

Deeper explanation — recognition, height and interval probability

The uniform distribution is the “fair rectangle” distribution. Equal widths have equal probabilities.

If a 2-unit interval has probability 0.20, then any other 2-unit interval inside the same uniform range also has probability 0.20.

TaskQuestion to askMethod
HeightHow wide is the full interval?1/(b−a)
BetweenHow wide is the wanted interval?(d−c)/(b−a)
Less thanHow far from lower bound to t?(t−a)/(b−a)
Picture method: Draw a rectangle, shade the wanted part, then calculate shaded base ÷ full base.
Cards 6.4–6.6 Less Than, Greater Than, CDF Shortcut
▼

Card 6.4 — P(X < t)

P(X < t) = (t−a)/(b−a)

Area from lower bound a up to t. Always subtract a!

X ~ Uniform(3.5, 5.5). P(X < 4.5)?
(4.5−3.5)/(5.5−3.5) = 1/2 = 0.5

0.5 — makes sense, 4.5 is the midpoint. ✓

Card 6.5 — P(X > t)

P(X > t) = (b−t)/(b−a) = 1 − P(X < t)

Area from t up to upper bound b.

X ~ Uniform(3.5, 5.5). P(X > 4)?
(5.5−4)/(5.5−3.5) = 1.5/2 = 0.75

0.75

Card 6.6 — CDF Shortcut for P(x₁ < X < x₂)

P(x₁ < X < x₂) = P(X < x₂) − P(X < x₁) = (x₂−a)/(b−a) − (x₁−a)/(b−a)
X ~ Uniform(3.5, 5.5). P(4 < X < 4.5)?
P(X < 4.5) = (4.5−3.5)/2 = 0.5 P(X < 4) = (4−3.5)/2 = 0.25 P(4 < X < 4.5) = 0.5 − 0.25 = 0.25
Deeper explanation — why you subtract the lower or upper bound

Uniform probabilities measure the fraction of the full interval that is shaded.

For P(X<t), the shaded region starts at the lower bound a, not at zero unless a=0. That is why the numerator is t−a.

For P(X>t), the shaded region starts at t and ends at the upper bound b. That is why the numerator is b−t.

ProbabilityShaded widthFormula
P(X<t)from a to t(t−a)/(b−a)
P(X>t)from t to b(b−t)/(b−a)
Most common uniform mistake: Using t/(b−a) when the lower bound is not zero.
Cards 6.7–6.8 Mean and Variance/SD
▼

Card 6.7 — Mean

E[X] = (a + b) / 2

The midpoint of the interval. The distribution is symmetric.

X ~ Uniform(3.5, 5.5)

E[X] = (3.5 + 5.5)/2 = 4.5

⚠ Trap

(b−a)/2 gives the half-width, not the mean. Use (a+b)/2.

Card 6.8 — Variance and SD

Var(X) = (b−a)²/12 σ = √[(b−a)²/12]
X ~ Uniform(0, 10)
Var = 100/12 = 8.3333 σ = √8.3333 ≈ 2.8868
⚠ Trap

If the question asks for SD, take the square root of the variance. Do not stop at 8.3333.

Deeper explanation — uniform centre and spread

The uniform mean is the midpoint because the rectangle is balanced perfectly in the middle.

The variance depends only on the width of the interval. A wider interval means values are more spread out.

Exponential Distribution Question Cards

Waiting time distributions — biggest traps: units + Poisson confusion

🔑 The Big Idea: Exponential = Waiting Time

What it models: how long you wait between events.

If customers arrive at rate λ = 12/hour, the exponential distribution tells you how long until the next customer arrives.

DistributionAsks

Deeper explanation — how exponential connects to Poisson

Poisson and exponential often appear together because they describe the same arrival process from two different angles.

Card 7.2 — Understanding λ

λ is the rate (events per unit time). It is NOT the waiting time.

"50 cars per minute" → λ = 50 per minute "12 calls per hour" → λ = 12 per hour If E[X] = 10 is given → λ = 1/10 = 0.1
⚠ Given Mean, Find λ

E[X] = 1/λ, so λ = 1/E[X]. If "mean waiting time = 10 seconds", then λ = 0.1 per second.

Card 7.3 — P(X < x) — "Within / Less Than"

P(X < x) = 1 − e^(−λx)
📌 Cars arrive at λ = 50/min. P(next car within 3 seconds)?
Convert 3 seconds to minutes: x = 3/60 = 0.05 min P(X < 0.05) = 1 − e^(−50 × 0.05) = 1 − e^(−2.5) ≈ 0.9179

Answer: 0.9179 — Units matched before substituting! ✓

Card 7.4 — P(X > x) — "More Than / After"

P(X > x) = e^(−λx) = 1 − P(X < x) ← complement
📌 Calls arrive at 12/hour. P(next call after 6 minutes)?
Convert λ: 12/60 = 0.2 per minute P(X > 6) = e^(−0.2 × 6) = e^(−1.2) ≈ 0.3012

Answer: 0.3012

⚠ Trap

1 − e^(−λx) gives LESS THAN. For greater than, use e^(−λx) directly.

Deeper explanation — reading lambda correctly

Lambda is a rate: events per time unit. It is not the time itself.

A high rate means events happen often, so you usually wait a shorter time. A low rate means events happen rarely, so waiting time tends to be longer.

Card 7.5 — Unit Conversion (CRITICAL)

⚠ The Most Common Exponential Error

λ and x MUST be in the same time unit before substituting into the formula.

SituationFix
λ = 50/min, x = 3 secondsOption A: convert x to minutes → x = 3/60 = 0.05 min, then use λ = 50/min
OR
Option B: convert λ to per second → λ = 50/60 ≈ 0.8333/sec, then use x = 3 sec
⚠ Do NOT multiply λ by 60 here — that would give λ per hour when x is in seconds.
λ = 12/hour, x = 3 minutesConvert: λ = 12/60 = 0.2/min OR x = 3/60 = 0.05 hours
λ = 2/week, x = 3 weeksNo conversion needed — both in weeks ✓
Deeper explanation — unit conversion as the main exponential safeguard

The exponent −λx must combine a rate and a time in matching units. That is the only way the units cancel.

For example, if λ=12/hour and x=6 minutes, you have two clean options:

  • Convert λ to per minute: 12/60=0.2/min, then use x=6 minutes.
  • Convert x to hours: 6/60=0.1 hours, then use λ=12/hour.

Both give λx = 1.2.

Exam trap: Do not mix 12/hour with 6 minutes directly as 12×6. That treats 6 minutes like 6 hours.

For an exponential distribution:

So the standard deviation equals the mean. This is unusual but useful.

A rate such as “50 per minute” is not enough to choose the distribution. The question’s random variable chooses the distribution.

Card 7.8 — Inverse Exponential (Percentile)

Given probability → find the time.

p = −(1/λ) · ln(1 − α) where α = the left-tail probability
📌 λ = 2. Find the 80th percentile.
α = 0.80 p = −(1/2) × ln(1 − 0.80) p = −0.5 × ln(0.20) p ≈ 0.8047

Answer: ≈ 0.8047 — 80% of waiting times are below 0.8047 time units.

⚠ Traps
  • Use ln(1 − α), NOT ln(α)
  • Use natural log (ln), not log₁₀
  • The negative sign is essential — without it the answer is negative
Deeper explanation — inverse exponential percentile logic

Inverse exponential questions ask for the time by which a certain percentage of events have occurred.

If the 80th percentile is 0.8047, that means 80% of waiting times are less than 0.8047 time units, and 20% are longer.

The formula comes from solving α = 1−e^(−λp) for p.

StepMove
1Start with α = 1−e^(−λp)
2Move terms: 1−α = e^(−λp)
3Take natural log: ln(1−α)=−λp
4Solve: p=−(1/λ)ln(1−α)
Trap: Use natural log ln, not log base 10.

Normal Approximation to the Binomial

The bridge topic — starts binomial, solved with normal methods + the 0.5 "tax"

🔑 The Big Idea

When n is large, a binomial distribution looks like a bell curve. Instead of adding up many individual binomial probabilities, we use the normal approximation — but we must pay the continuity correction tax of 0.5 because we're converting from discrete to continuous.

Deeper explanation — why normal approximation saves time

An exact binomial cumulative probability can require adding many terms. For example, P(X>70) might require summing P(71)+P(72)+....

When the binomial distribution is large enough and not too skewed, its bar chart looks close to a bell curve. The normal approximation replaces a long binomial sum with one normal area.

But: The normal curve is continuous and the binomial is discrete. That is why the 0.5 continuity correction is not optional.
Cards 8.1–8.3 Recognition, Checks, μ and σ
▼

Card 8.1 — Recognition

Look for binomial setup AND the word "approximate":

  • Fixed number of trials n
  • Each trial is success/failure with probability π
  • Asks for cumulative or exact probability with large n
  • Often says "find the approximate probability"

Card 8.2 — Approximation Checks

Check 1: nπ > 5 (expected successes > 5) Check 2: n(1−π) > 5 (expected failures > 5)
📌 X ~ Bin(150, 1/3). Check allowed?
nπ = 150 × 1/3 = 50 > 5 ✓ n(1−π) = 150 × 2/3 = 100 > 5 ✓ → Normal approximation allowed.

Card 8.3 — Finding μ and σ

μ = nπ σ = √[nπ(1−π)] ← take the square root!
📌 X ~ Bin(150, 1/3)
μ = 50 σ² = 150 × (1/3) × (2/3) = 100/3 σ = √(100/3) ≈ 5.7735
⚠ Trap

σ² = nπ(1−π), so σ = √[nπ(1−π)]. Using the variance in z-scores instead of σ is the most common error.

Deeper explanation — mean, variance and SD for the approximation

When approximating X~Binomial(n,π), the normal curve uses the same centre and spread as the binomial.

QuantityFormulaUse
Meanμ=nπCentre of approximate normal curve
Varianceσ²=nπ(1−π)Spread squared
Standard deviationσ=√[nπ(1−π)]Used in z-score
z-score warning: Always use σ, not σ², in z=(x−μ)/σ.
Deeper explanation — why both approximation checks matter

The two checks make sure the binomial distribution has enough expected successes and expected failures to look roughly bell-shaped.

CheckMeaning
nπ>5Enough expected successes
n(1−π)>5Enough expected failures

If one side is too small, the binomial distribution is too skewed, and the normal approximation may be poor.

Trap: Passing one check is not enough. Both must pass.
Card 8.4 Continuity Correction — The ±0.5 Tax
▼

The binomial counts whole numbers. The normal distribution is continuous. To approximate a discrete value with a continuous area, each whole number becomes a small interval:

X = 60 (discrete) → 59.5 < Xₐ < 60.5 (continuous area)
Original Wording Corrected Boundary Why
P(X = x) — exactly P(x−0.5 < Xₐ < x+0.5) Single bar → small interval
P(X ≤ x) — at most P(Xₐ < x+0.5) Include x, so go to x+0.5
P(X < x) — fewer than P(Xₐ < x−0.5) X<x means X≤x−1, stop at x−0.5
P(X ≥ x) — at least P(Xₐ > x−0.5) Include x, start from x−0.5
P(X > x) — more than P(Xₐ > x+0.5) Exclude x, start from x+0.5
Deeper explanation — choosing the correct side of the 0.5 boundary

Continuity correction is easiest if you think of each whole number as a tiny box.

The number 60 owns the interval from 59.5 to 60.5. So if the wording includes 60, your boundary must include that box.

WordingDoes it include x?Boundary
At most xYesGo up to x+0.5
Fewer than xNoGo up to x−0.5
At least xYesStart at x−0.5
More than xNoStart at x+0.5
One-line memory: Included value? Move outward by 0.5 to include its box.
Cards 8.5–8.10 Worked Examples: Exact, At Least, Fewer, More, At Most, Full Recipe
▼

Using X ~ Bin(150, 1/3) throughout: μ = 50, σ ≈ 5.7735

Card 8.5 — Exactly x: P(X = 60)

Correction: P(59.5 < Xₐ < 60.5) z₁ = (59.5 − 50) / 5.7735 ≈ 1.65 z₂ = (60.5 − 50) / 5.7735 ≈ 1.82 P = P(Z<1.82) − P(Z<1.65) = 0.9656 − 0.9505 = 0.0151

P(X = 60) ≈ 0.0151

Deeper explanation — why exact binomial values need two z-scores

An exact binomial value like X=60 is one bar in the binomial histogram. To approximate that bar with a normal curve, you need the area covering the full width of that bar.

That is why X=60 becomes:

59.5 < Xₐ < 60.5

This creates a between-values normal problem, so you calculate two z-scores and subtract.

Trap: Do not calculate P(Xₐ=60). For a normal variable, exact point probability is 0.

Card 8.6 — At Least: P(X ≥ 60)

Correction: P(Xₐ > 59.5) z = (59.5 − 50) / 5.7735 ≈ 1.65 P(Z < 1.65) = 0.9505 P(X ≥ 60) = 1 − 0.9505 = 0.0495

P(X ≥ 60) ≈ 0.0495

Deeper explanation — at least includes the value

“At least 60” means 60 or more. Since 60 is included, you start at the lower edge of the 60-bar, which is 59.5.

So:

P(X≥60) ≈ P(Xₐ>59.5)

This is a right-tail normal probability, so after finding the left-tail, subtract from 1.

Trap: Using 60.5 would exclude the 60-bar and would calculate P(X>60), not P(X≥60).

Card 8.7 — Fewer Than: P(X < 60)

X<60 means X≤59 → Correction: P(Xₐ < 59.5) z = (59.5 − 50) / 5.7735 ≈ 1.65 P(Z < 1.65) = 0.9505

P(X < 60) ≈ 0.9505

Deeper explanation — fewer than excludes the value

“Fewer than 60” means 59 or less. It does not include 60.

So the last included binomial value is 59, whose upper boundary is 59.5.

P(X<60) = P(X≤59) ≈ P(Xₐ<59.5)

Routine: For strict inequalities, rewrite them using whole numbers first. X<60 becomes X≤59.

Card 8.8 — More Than: P(X > 70)

Correction: P(Xₐ > 70.5) z = (70.5 − 50) / 5.7735 = 20.5 / 5.7735 ≈ 3.55 P(Z < 3.55) ≈ 0.9998 P(X > 70) = 1 − 0.9998 = 0.0002

P(X > 70) ≈ 0.0002

Deeper explanation — more than excludes the value

“More than 70” means 71, 72, 73, and so on. It excludes 70.

The first included value is 71, and the boundary between 70 and 71 is 70.5.

P(X>70) ≈ P(Xₐ>70.5)

Trap: P(Xₐ>69.5) would include 70, so it would represent P(X≥70), not P(X>70).

Card 8.9 — At Most: P(X ≤ 70)

Correction: P(Xₐ < 70.5) z = (70.5 − 50) / 5.7735 ≈ 3.55 P(Z < 3.55) ≈ 0.9998

P(X ≤ 70) ≈ 0.9998

Deeper explanation — at most includes the endpoint

“At most 70” means 70 or less, so the 70-bar is included.

The upper edge of the 70-bar is 70.5, so:

P(X≤70) ≈ P(Xₐ<70.5)

This is a left-tail normal probability.

Matching pair: P(X>70) uses 70.5 as a right-tail. P(X≤70) uses the same boundary as the left-tail complement.

Card 8.10 — The Full 9-Step Recipe

  1. 1
    Identify binomial: n, π, event
  2. 2
    Check: nπ > 5 AND n(1−π) > 5
  3. 3
    Calculate μ = nπ
  4. 4
    Calculate σ = √[nπ(1−π)]
  5. 5
    Apply continuity correction (use the table above)
  6. 6
    Convert corrected boundary to z-score(s)
  7. 7
    Use calculator for left-tail probability
  8. 8
    Use complement / subtraction if needed
  9. 9
    Interpret in context
Deeper explanation — using the full normal approximation recipe without losing marks

The recipe exists because this topic has several small traps stacked together. Missing one step can change the answer even if the rest of your method is good.

  1. Identify binomial first.
  2. Check whether approximation is allowed.
  3. Compute μ and σ.
  4. Translate the inequality wording.
  5. Apply continuity correction.
  6. Convert to z and use normal area.
Common cascade error: If you use variance instead of SD, every z-score afterward is wrong. If you use the wrong continuity correction, the tail area is for the wrong event.

Normality evaluation checklist
  1. Measures: check whether mean, median and mode are equal or approximately equal.
  2. Empirical rule: check roughly 68%, 95% and 99.7% within 1, 2 and 3 standard deviations.
  3. Graphs: use stem-and-leaf, boxplot, relative frequency polygon or histogram to judge symmetry and bell shape.
  4. Normal probability plot: sort data, create index j, calculate αj = j/(n+1), find matching z-values, then plot X against Z. A near-linear pattern supports normality.
⚠ Normality trap

Do not say data is normal just because it is continuous. Normality requires symmetry/bell-shape evidence, not just a measured variable.
