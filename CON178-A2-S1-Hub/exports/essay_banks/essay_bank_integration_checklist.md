# Essay Bank Integration Checklist

## 1. Purpose

This checklist tracks whether curated essay-bank content has been added before the HTML hub build.

## 2. Required Curated Essay Bank Files

| File | Status | Notes | Required before final HTML build? |
| --- | --- | --- | --- |
| `theme_3_essay_banks_final.md` | MISSING | Must be added from curated Theme 3 essay bank content. | YES |
| `theme_4_essay_banks_final_v2.md` | MISSING | Must be added from audited Theme 4 FINAL v2 essay bank content. | YES |

## 3. Required Essay Structure

Each essay bank should include:

* possible exam questions;
* core thesis;
* key authorities;
* full exam-ready study answer;
* case/event/doctrine boxes;
* 5-mark version;
* 10-mark version;
* 15-mark version or structure;
* how to adapt this in the exam;
* common mistakes;
* what to memorise;
* 70/80/90+ upgrade guide.

## 4. Visual Design Requirement for HTML Hub

The essay banks must not appear as plain walls of text. They should remain mostly in essay-answer paragraph format, but visually structured with headings, subheadings, colour-coded boxes, authority chips, case/event boxes, exam tips, warning boxes, memory triggers, and 5/10/15-mark versions.

Use this colour hierarchy:

* Dark purple: main essay titles and major hub headings.
* Pastel purple: essay bank containers.
* Dark blue: major subsections inside essays.
* Light blue: explanatory blocks.
* Dark green: key concepts, rules and doctrines.
* Pastel green: examples and applied illustrations.
* Pastel yellow: definitions.
* Light orange: exam tips and “how to answer” blocks.
* Darker orange: warnings and common mistakes.
* Red: critical precision points, non-negotiable corrections and high-risk errors.
* Pink: memory triggers and memorisation boxes.

The main full essay answers must remain visible and mostly paragraph-based. Do not convert everything into disconnected bullet points. Do not hide main content too aggressively in collapsible sections.

## 5. Build Gate

Do not build the final HTML hub until:

* `combined_essay_source_audit.md` approves hub build or approves it with warnings;
* `theme_3_essay_banks_final.md` exists;
* `theme_4_essay_banks_final_v2.md` exists;
* the essay-bank files have been reviewed for obvious accuracy and structure issues.
