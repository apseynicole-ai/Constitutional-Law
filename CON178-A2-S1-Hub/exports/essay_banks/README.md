# CON178 A2 S1 Essay Banks

The final HTML hub should be built from both:

1. the combined source file, and
2. curated essay-bank files.

The curated essay-bank files should contain the final Theme 3 and Theme 4 essay banks in exam-ready structure.

Theme 4 has already gone through an audit/edit cycle and should be treated as curated final-v2 content once added.

Theme 3 essay banks have been drafted and should be added as curated content, then audited before hub build.

Do not regenerate essay banks from raw sources if curated essay-bank files exist.

Do not reduce the essays into short notes.

The essay banks should preserve the 5/10/15-mark versions, authority references, case/event boxes, common mistakes, memory triggers, and 70/80/90+ upgrade guides.
