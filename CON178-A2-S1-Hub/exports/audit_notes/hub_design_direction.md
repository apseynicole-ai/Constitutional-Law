# CON178 A2 S1 Hub Design Direction

## 1. Updated Study-Hub Approach

This hub must be built as an essay-note and model-answer study hub, not as a shallow summary hub.

The structure should support the way I learn best:
- essay-style explanations
- theme-based long-form notes
- case-focused model paragraphs
- exam-answer frameworks
- mini model answers
- issue -> principle/provision -> authority/case -> application -> conclusion
- memory blocks
- common mistake warnings
- last-minute answer templates

## 2. Why This Approach Is Needed for CON178

The A2 assessment is not only testing content recognition. It includes:
- multiple-choice questions
- knowledge-based questions
- case-based questions
- critical engagement questions
- constitutional rights/provisions
- prescribed cases
- tutorial and A1 content from different angles

Therefore, the hub must teach both:
1. what the law is, and
2. how to write the answer.

## 3. Hub Content Architecture

The final hub should be organised as:

### A. A2 Scope Command Centre
- exact scope
- lecturer warnings
- question types
- what cannot be skipped

### B. Theme Essay Notes
For each theme:
- full essay-style explanation
- key rules/principles
- constitutional provisions
- cases
- examples
- examiner focus
- how to write the theme in an exam

### C. Case Bank
For each case:
- facts
- issue
- court reasoning
- judgment
- constitutional significance
- how to use the case in an answer
- model paragraph

### D. Model Answer Bank
Include:
- short-answer models
- 5-mark structures
- 10-mark structures
- essay structures
- critical engagement frameworks

### E. Common Mistakes and Feedback Bank
Use:
- A1 feedback
- tutorial feedback
- lecturer warnings
- referencing/writing mistakes
- spaghetti-answer warnings

### F. Last-Minute Revision
Include:
- what to memorise
- provision bank
- case one-liners
- emergency answer structures

## 4. Treatment of Student-Created DOCX Notes

The DOCX files in:
CON178-A2-S1-Hub/sources_raw/08_student_essay_notes_model_answers/

must be treated as high-value study material because they may contain:
- essay-style explanations
- model answers
- theme summaries
- case law notes
- exam-ready phrasing

They must not replace prescribed sources, but they should be used to shape the final hub's answer-writing style.

## 5. Important Rule

Do not compress these notes into shallow summaries. Preserve legally relevant detail and convert them later into structured Markdown before integrating them into the combined source and final hub.
