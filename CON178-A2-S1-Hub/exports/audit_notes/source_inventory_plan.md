# CON178 A2 S1 Source Inventory Plan

## 1. Purpose of This Inventory

This inventory exists to identify, organise, and track every source needed for the CON178 A2 S1 Constitutional Law Study Hub. The A2 S1 scope covers all Semester 1 Constitutional Law content, so no section, theme, prescribed reading, tutorial item, lecturer instruction, case, constitutional provision, or assessment-related note should be excluded.

The inventory must support a hub that preserves all legally relevant detail. Each source should be tracked so that the final study material can be organised around issue -> principle/provision -> authority/case -> application -> conclusion, without reducing the content into shallow summaries.

## 4. Source Status Labels

- MISSING: The source has been identified as necessary but is not yet available in the repo or source workspace.
- AVAILABLE IN REPO: The source exists somewhere in the repo but has not necessarily been copied into the hub source workflow.
- NEEDS CONVERSION: The source is available and should be converted into a workable text or markdown format later.
- CONVERTED RAW: The source has been converted into raw text or markdown but has not yet been cleaned or checked.
- CLEANED: The converted source has been checked, cleaned, and preserved with legally relevant detail intact.
- MERGED INTO HUB: The source has been incorporated into the study hub in the correct issue -> principle/provision -> authority/case -> application -> conclusion structure.
