# CON178 A2 S1 Constitutional Law Study Hub

This repo is for CON178 A2 S1 study materials.

The A2 scope is all Semester 1 Constitutional Law content.

The hub must preserve all legally relevant detail.

The hub must be organised around:

- issue
- principle/provision
- authority/case
- application
- conclusion

Source material must not be reduced into shallow summaries.
